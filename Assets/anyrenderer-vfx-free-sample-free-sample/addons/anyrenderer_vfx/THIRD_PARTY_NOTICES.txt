This add-on contains no third-party code, shaders, textures or fonts.

* All shader code and all GDScript code was written by Mothlight Studio for
  this pack.
* Credit (no code copied, no licence obligation):
  shaders/fx_common.gdshaderinc, function arfx_scramble — structure inspired
  by MurmurHash3 fmix32 (public domain), the 32-bit finalizer of MurmurHash3
